# 🛒 Customer Churn Intelligence

An end-to-end machine learning application for **customer churn prediction, 90-day spend forecasting, and explainable retention recommendations**.

The project combines a production-style **FastAPI backend**, machine learning models, **SHAP-based explainability**, and an interactive customer dashboard to turn customer data into actionable retention insights.

---

## 🚀 Overview

Customer churn is not only about identifying *which* customers are likely to leave — businesses also need to understand **why they are at risk** and **how valuable those customers may be in the near future**.

This project addresses those questions through three connected ML components:

* **Churn Classification** — predicts the probability that a customer will churn.
* **90-Day Spend Regression** — estimates the customer's expected spend over the next 90 days.
* **SHAP Explainability** — identifies the customer-level factors contributing most to the churn prediction.

The application combines these outputs into a single customer intelligence view containing:

> **Churn Risk + Churn Probability + 90-Day Predicted Spend + SHAP Drivers + Retention Recommendation**

---

## ✨ Key Features

### 🔴 Churn Prediction

An **XGBoost classification model** predicts whether a customer is likely to churn.

The API returns both the predicted class and probability, allowing the dashboard to distinguish between low-, medium-, and high-risk customers.

**Model evaluation:**

* **ROC-AUC:** `0.7251`
* Model: **XGBoost Classifier**

---

### 💰 90-Day Customer Spend Prediction

The application also includes a **Random Forest regression model** that predicts the customer's expected spending over the next **90 days**.

This complements the churn model by adding a customer-value dimension to the retention decision.

For example, a customer with:

* high churn probability, and
* high predicted 90-day spend

may deserve a higher retention priority than a low-value customer with the same churn probability.

The prediction is generated by the backend and displayed directly in the customer dashboard.

#### Example Regression API Response

```json
{
  "predicted_90_day_spend": 3238.76,
  "currency": "GBP",
  "model": "RandomForestRegressor",
  "prediction_horizon": "90_days",
  "features_used": 6
}
```

This makes the regression model a first-class part of the application rather than a standalone notebook experiment.

---

### 🔍 Explainable AI with SHAP

The system uses **SHAP (SHapley Additive exPlanations)** to make individual churn predictions interpretable.

For each customer, the application can identify factors that push the prediction toward:

* **Higher churn risk**
* **Lower churn risk**

This provides a practical explanation layer between the raw ML prediction and the business recommendation.

Instead of simply showing:

> `Churn probability: 82%`

the dashboard can answer:

> **Why is this customer at risk?**

---

### 🎯 Retention Recommendations

The model outputs can be combined to support targeted retention decisions.

Examples include:

* Prioritize high-risk customers.
* Identify customers with high predicted future value.
* Investigate the strongest negative SHAP drivers.
* Use customer-level insights to guide retention actions.

The goal is to move from **prediction → explanation → action**.

### Request Flow

1. The user selects or submits customer information through the **web dashboard**.
2. The frontend sends the customer data to the **FastAPI REST API**.
3. FastAPI passes the relevant features to the ML components.
4. The **XGBoost classifier** generates the churn prediction and probability.
5. The **Random Forest regressor** estimates expected 90-day spend.
6. **SHAP** calculates feature-level explanations for the churn prediction.
7. The API returns the combined results as structured JSON.
8. The dashboard presents the predictions, explanations, and resulting business insight to the user.

* Health/API availability checks

## ⚙️ Running Locally

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd customer-churn-intelligence
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

Or on macOS/Linux:

```bash
source .venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Start the FastAPI backend

```bash
uvicorn main:app --reload
```

The API will be available locally through the configured FastAPI server.

### 5. Start the frontend

Run the frontend using the command defined by the frontend application.

Make sure the frontend is configured to point to the correct FastAPI API URL.
